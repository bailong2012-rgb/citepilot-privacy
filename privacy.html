CitePilot 快引隐私政策

适用产品：CitePilot 快引 · 离线期刊文献库
适用版本：浏览器扩展 v1.0.0
政策版本日期：2026-10-04

运营者：GGBME（个人运营）
隐私与支持联系：jtpbme@163.com

本版在浏览器本地处理你主动导入的文献，不自动上传文献库。打开外部原文网站需要联网；本政策页面的托管服务与离线扩展的数据处理是两回事。

1. 适用范围

本政策说明 CitePilot 离线浏览器扩展如何处理文献信息，以及本政策页面和支持渠道涉及的数据处理。本版不要求注册、登录或付款。本政策不将尚未推出的会员、云同步或其他服务视为现有功能。

2. 我们处理哪些信息

在你主动选择文件后，扩展会在本机读取和解析文件，用于导入预览；只有确认导入后，文献记录才会写入本地库。这些信息包括标题、作者姓名、期刊、年份、DOI、原文链接、摘要、关键词、主题分类、文章类型、卷期页码和来源引用等。你输入的检索词仅用于本地筛选，不会通过扩展发送给运营者。

文件选择器只允许读取你选中的文件，不授予任意读取其他目录的权限。原始文件不会被改写。

3. 处理目的和保存位置

导入内容用于展示文献、检索与筛选、打开原文链接、生成引用文件和备份。文献库保存在当前浏览器配置下、本扩展来源的 IndexedDB 数据库中。解析与检索在本机完成，不会通过扩展上传给 GGBME。程序和 Excel 解析依赖均随安装包本地提供。

4. 本版不执行的行为

本版不读取网页正文、浏览历史、Cookie、浏览器账户密码或支付信息，不向网站注入脚本，不集成广告、遥测、云同步或远程分析服务。不会出售你的文献库，不会将文献数据用于广告、信用评估或与本扩展核心功能无关的目的。

5. 外部原文网站与主动导出

点击 DOI 或原文链接会在新标签页访问 DOI 服务或出版商网站。DOI 解析入口使用 HTTPS；来源文件中的其他链接可能使用 HTTP，安全性取决于目标网站。浏览器和目标网站可能处理 IP 地址、Cookie 等访问数据，适用其各自政策。扩展不会把完整文献库发送给这些网站。

下载 ENW、备份全库或“分享当前期刊”会生成包含文献元数据的本地明文文件，不会自动上传或发送给其他人。你自行决定保存位置和后续分享对象，请确保有权使用、导入及分发相关资料。

6. 保留、备份、访问与删除

文献库保留在当前浏览器配置中，直至本地扩展数据被清除、扩展被卸载或浏览器配置被删除。你可以在工作台查看文献，并使用“备份全库”导出 JSON；也可以在另一安装中手动导入备份。本版没有自动云备份，丢失后的恢复取决于你保存的备份。

要删除本地库，可在备份后卸载扩展，或使用浏览器开发者工具清除本扩展来源的本地数据。已经下载的文件和原始文件不会自动删除，需要你另行管理。本版不提供逐条编辑、逐条删除或在线账户注销功能。如需更正数据，请先核对原始来源并备份，再准备正确的导入文件；重复导入不保证覆盖原有非空字段。

7. 安全边界

扩展没有另加应用层加密，不是保密资料保险库。能访问你的设备或浏览器配置的人或软件可能访问这些本地资料；导出文件也未加密。请使用受保护的系统账户并妥善保管备份，不要导入患者资料、账户凭据或其他敏感、机密材料。

8. 联系支持时的信息

如果你通过邮件或商店支持渠道主动联系 GGBME，我们会收到你提交的联系方式、问题描述及主动附上的材料，用于回复、排查问题和维护工具。仅在处理问题及必要的后续维护期间保留支持材料，法律另有要求的除外。你可以通过 jtpbme@163.com 请求查询、更正或删除你提交的支持资料。

请只提交必要且已脱敏的样本，不要发送完整私人文献库、密码或患者信息。邮箱服务商网易及你选择的邮件服务商、Google 商店支持渠道可能按照各自政策处理通信内容；我们不会将支持材料用于无关营销或出售给其他方。

9. 隐私政策网页托管

本政策网页使用 GitHub Pages 托管。访问网页时，GitHub 可能为安全目的记录访问者的 IP 地址等信息，详见 GitHub 隐私声明。本页面不添加分析脚本、广告、表单或 Cookie。访问此页不会把你的扩展文献库上传到 GitHub。

10. 政策更新与联系

如产品的数据处理方式变化，GGBME 将更新本政策及商店披露。新增账户、联网或收费服务时，会说明其对应的数据处理，不以本版的离线说明代替新功能披露。关于本政策或数据处理，请联系 jtpbme@163.com。
