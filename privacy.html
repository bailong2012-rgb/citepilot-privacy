v1.1 起支持下载公共期刊库更新。个人文献、原始文件和检索词仍在本机处理，不会通过扩展上传给 GGBME 或 GitHub。公共数据请求会使托管方接收到必要的网络访问数据。

1. 版本与适用范围

v1.0 为个人离线库，不自动请求公共数据；v1.1 增加公共期刊库下载与缓存。读者无需注册、登录或付款。本扩展不提供读者会员、支付、广告或行为分析。独立管理员发布工具见第 8 节。

2. 本地处理的信息

主动选取的文献文件可能包含标题、作者、期刊、年份、DOI、摘要、关键词、分类、卷期页码和引用信息。扩展在本机解析预览，经确认后写入个人库。检索词仅用于本地筛选。文件选择不授予任意读取目录权限，原始文件不会改写。

3. 公共期刊库与网络请求

公共库包括获准公开分发的文献元数据。安装含起始版本；打开扩展、工作台重新获得焦点（请求间隔至少一分钟）、工作台持续打开约每 30 分钟、点击“检查更新”时，会通过 HTTPS 向 bailong2012-rgb.github.io 请求公共版本清单和必要的文献 JSON。工作台关闭时无后台轮询。请求不包含个人库、搜索词、用户标识或认证令牌，不发送 Cookie 凭据，不执行远程脚本。

GitHub Pages 作为托管方可能处理 IP、请求时间、请求路径、浏览器网络信息等日志，详见 GitHub 隐私声明。请求用于公共数据获取和服务安全，不用于跟踪你搜索或阅读的文章。扩展不加入遥测、广告或分析代码。

4. 保存位置与用途

个人库和公共缓存分别存于当前浏览器配置下、本扩展来源的 IndexedDB。公共更新可新增、更正或移除公共记录，不覆盖个人库。网络或校验失败保留旧数据。检索、筛选、引用导出在本机完成，所有执行代码与 Excel 解析依赖随安装包提供。

5. 原文访问、导出和分享

点击 DOI 或原文链接访问外部网站，目标网站与浏览器按其政策处理 IP、Cookie 等访问数据。DOI 入口使用 HTTPS，来源其他链接可能为 HTTP，请注意目标安全。扩展不向原文网站发送完整库。ENW、个人备份、公共副本和期刊分享生成本地明文文件，不自动公开发布。后续分享由你决定，请确认使用及分发权限。

6. 保留、备份和删除

文献保留至扩展卸载、扩展存储清除或浏览器配置删除。个人库可“备份个人库”为 JSON 并在另一安装主动导入恢复；没有自动云备份，卸载前请备份。公共缓存可重新获取。已下载文件和原始文件需另行管理与删除。

本版个人库无逐条编辑、删除，重复导入主要补充缺失字段，不保证覆盖非空字段。可在备份后卸载或清除该扩展存储以完全删除。公共库错误可邮件反馈核实后更正。禁用扩展可停止公共请求；离线时请求失败但缓存仍可用。

7. 安全边界

不读取网页正文、历史、Cookie、浏览器密码或支付信息，不注入页面脚本，不出售个人库或将其用于广告、信用评估及无关用途。固定域名权限仅用于公共数据读取。存储和导出未另加应用层加密，拥有设备访问权的人或软件可能读取资料。请勿导入患者资料、密码及其他机密内容。

8. 管理员独立发布工具

发布工具不随读者扩展分发。管理员在本机回环地址运行，导入与预览在本机进行。确认发布后，公共文献元数据、摘要和分类等写入 GitHub 公共仓库并由 Pages 分发，可能被公众复制和索引。管理员须确认公开授权，不上传敏感资料。原始 Excel、EndNote 数据库或 PDF 不自动上传。

管理员输入的 GitHub 令牌仅在当前页面及请求处理内存中使用，通过 HTTPS 发送 GitHub API，供指定仓库读取和发布；工具不保存令牌到文件、公共库、读者插件或日志。建议仅授权目标仓库 Contents 读写权限并定期更换，不向读者或支持渠道发送令牌。

9. 支持渠道和政策页面

主动邮件或商店联系时，我们收到你提交的联系方式、问题描述及材料，仅用于回复、排查与必要维护，法律另有要求除外。可联系 jtpbme@163.com 查询、更正或删除主动提交的支持资料。请只发送必要脱敏样本，不发送私人库、令牌、患者资料。网易、你使用的邮件服务商和 Google 支持渠道按各自政策处理通信。

本页面由 GitHub Pages 托管，访问时 GitHub 可能记录网络日志。页面无广告、分析脚本或表单，访问不会上传个人库。

10. 更新与联系

数据处理变化时会更新本政策及商店披露；此前离线版本说明不替代新版联网披露。问题请联系 jtpbme@163.com。CitePilot 为独立整理工具，不是 EndNote 官方产品。
